Key features

  • Adaptive turn-taking — prosody-aware decisions about when an NPC should start, hold, or yield the floor
  • Backchannels — short verbal and non-verbal acknowledgments with cooldowns and action variety
  • Gaze state machine — NPCs direct attention to the active speaker and other agents in a believable way
  • Phased interview flow — structured stages (intro, questions, wrap-up) governed by an activity-style flow
  • Local-first inference — STT, LLM, and (optionally) TTS all run on the same machine
  • Automated evaluation — interview transcripts are scored after the session ends; unit tests cover the evaluator in evaluator.test.ts
